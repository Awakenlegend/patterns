
# ✨ C++ Pattern Programs

Hi there! 👋  
This is a collection of simple **C++ pattern programs** that I created while learning loops and basic programming. These programs print cool shapes like triangles, squares, pyramids, and more using stars (`*`) and numbers.

## 📚 What’s Inside?

Here are some of the pattern programs in this repo:

- ✅ `Floyd's Triangle.cpp` – Prints Floyd’s triangle with increasing numbers
- ✅ `butterfly.cpp` – A butterfly shape using stars
- ✅ `hallow_diamond.cpp` – A hollow diamond pattern
- ✅ `inverted_triangle.cpp` – A reverse triangle shape
- ✅ `pyramid.cpp` – A classic centered pyramid
- ✅ `reverse-triangle.c++` – Upside-down right-angled triangle
- ✅ `square_patterns.cpp` – Prints solid and hollow squares
- ✅ `triangle-patterns.c++` – Right-angle, mirrored, and number triangles

These programs helped me understand **nested loops**, **if-else conditions**, and how to control output formatting in C++.

## 🚀 How to Run

If you want to try them out:

1. **Clone this repo** (or download it):
   ```bash
   git clone https://github.com/Awakenlegend/patterns.git
   cd patterns
   ```

2. **Compile and run** any file:
   ```bash
   g++ filename.cpp -o output
   ./output
   ```

   Replace `filename.cpp` with the file you want to run.
